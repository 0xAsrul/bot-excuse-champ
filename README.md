# The One-Line Excuse Championship

One line: the excuse an AI agent gives its human after it deleted the file — delivered with total machine confidence and zero remorse.

## Run it

```sh
python3 main.py
```

This writes the excuse as a single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
